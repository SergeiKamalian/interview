# 00-🟡 — Project Setup

Этот большой task-блок отвечает за подготовку структуры проекта и системы задач.

На этом этапе мы не пишем backend-код и frontend-код.

---

## Цель блока

Создать понятную систему, по которой дальше можно будет работать с Cursor:

- вся документация лежит в `docs/`;
- все задачи лежат в `docs/tasks/list/`;
- большие задачи являются папками;
- подзадачи лежат внутри `subtasks/`;
- Cursor выполняет одну подзадачу за раз;
- статус виден по emoji в названии папки/файла;
- общий прогресс виден в `STATUS.md`.

---

## Что входит

В этот блок входит:

- создание `docs/tasks/README.md`;
- создание `docs/tasks/STATUS.md`;
- создание `docs/tasks/CURSOR_RULES.md`;
- создание папки `docs/tasks/list/`;
- создание первого task-блока `00-🟡-project-setup/`;
- создание `README.md` и `TASKS.md` внутри task-блока;
- создание `subtasks/`;
- создание первых subtask-файлов;
- создание placeholder-папок для будущих больших блоков.

---

## Что НЕ входит

В этот блок не входит:

- создание NestJS backend;
- создание React frontend;
- установка пакетов;
- Docker;
- MySQL;
- Redis;
- GraphQL;
- auth;
- question bank;
- AI evaluation;
- dashboard;
- voice/video;
- ATS;
- deployment.

---

## Главный результат

После завершения этого блока у нас должна быть структура задач, в которой понятно:

- что сейчас делаем;
- что уже done;
- что следующее;
- где лежат подробные подзадачи;
- как давать Cursor задачи.
